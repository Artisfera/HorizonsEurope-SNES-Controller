# HorizonsEurope-SNES-Controller

**Run, or die!**

This game is inspired by the popular childhood game of tag, except it takes place inside a maze and is much less friendly...

It was created for the Horizons Europa hackathon in Berlin. Our randomly selected theme object was an SNES controller, which inspired the retro style of the game. Since most of our team mainly works with hardware, we also designed the game so that its concept could later be ported to microcontrollers.

## How to Play

### Player 1: Tagger

The first player controls the Tagger using a keyboard.

The Tagger has a flashlight that can shine through the glass walls of the maze to find the Runner. The goal is to stop the Runner from reaching the exit and winning.

### Player 2: Runner

The second player controls the Runner using an SNES controller.

This adds an extra challenge because the Tagger cannot see which direction buttons the Runner is pressing. The Runner is not normally visible on the screen. From time to time, a flash briefly reveals their position, helping both the Runner and the Tagger locate each other.

The Runner's goal is to reach the exit before being caught by the Tagger.

**Have fun!**
